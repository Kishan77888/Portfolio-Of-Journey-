A modern, high-performance, responsive cybersecurity operations portfolio showcasing hands-on competencies in **SIEM telemetry monitoring**, **behavioral anomaly detection**, **MITRE ATT&CK incident triage**, and **packet inspection**.

Designed with a rich, interactive Command Center aesthetic featuring real-time 3D telemetry, frequency synchronization (350Hz, 432Hz, 540Hz), live visitor IP attribution, an interactive terminal, and dark/light mode support.

---

## ⚡ Key Highlights & Features

- **🌐 Live Perimeter Telemetry & Ingress History**: Real-time client public IP resolution, geolocation attribution, device fingerprinting, and session history stream.
- **🛰️ Interactive 3D Cyber Core**: Responsive Three.js morphing liquid core with particle telemetry dust and dynamic theme-aware crystal shaders.
- **📡 Synced Detection Rate (350Hz, 432Hz, 540Hz)**: Cross-component frequency synchronization between the Hero HUD console and the Bento grid.
- **💻 Interactive SOC Terminal**: Integrated terminal shell (`help`, `whoami`, `skills`, `projects`, `certs`, `history`, `ip`, `threats`).
- **🎯 MITRE ATT&CK Mapping**: Every featured project and lab writeup mapped to enterprise adversary techniques.
- **🌓 Seamless Theme Engine**: Pristine Dark Mode (Deep Cosmic Void) and high-contrast Light Mode (Modern Security Command Center).
- **📱 Mobile-First Optimization**: Tailored for all screen sizes from smartphones to ultra-wide displays.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Kishan77888/Portfolio-Of-Journey-.git

# Navigate to project folder
cd Portfolio-Of-Journey-

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the portfolio locally.

### Production Build

```bash
npm run build
```

The production assets will be generated in the `dist/` directory.

## 🚢 GitHub Pages Deployment

This repository includes an automated GitHub Actions deployment workflow at `.github/workflows/deploy.yml`.

Whenever you push to the `main` branch, the portfolio is automatically built and published to:
**https://kishan77888.github.io/Portfolio-Of-Journey-/**

### One-Time Setup in GitHub Repository Settings:
1. Go to **Settings** ➔ **Pages** in this GitHub repository.
2. Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
3. Pushes to `main` will automatically build and publish the live site!
